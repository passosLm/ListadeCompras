# 🛒 Lista de Compras App

Aplicativo móvel de gerenciamento de lista de compras desenvolvido com React Native e Expo.

## 📱 Telas do Aplicativo

| Tela         | Descrição                                 |
| ------------ | ----------------------------------------- |
| 🛒 Lista     | Tela principal com lista de compras       |
| ➕ Adicionar | Adicionar item com categoria e quantidade |
| 🔍 Detalhes  | Visualizar e editar detalhes do item      |
| 👤 Perfil    | Login e criação de conta                  |
| ⚙️ Config    | Configurações do aplicativo               |

## 🔧 Componentes React Native Utilizados

- **View** — estrutura de layout de todas as telas
- **Text** — exibição de títulos e informações
- **TextInput** — campos de entrada de dados
- **TouchableOpacity** — botões interativos
- **FlatList** — lista de itens com rolagem
- **Image** — exibição de imagens
- **ScrollView** — rolagem nas telas de formulário
- **Switch** — toggles na tela de configurações
- **Flexbox** — layout responsivo em todas as telas
- **Navegação entre telas** — via Expo Router com abas
